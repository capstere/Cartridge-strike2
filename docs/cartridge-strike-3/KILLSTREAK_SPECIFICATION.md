# Mandatory killstreak specification v1

| ID / slot | Threshold | Duration | Initial effect |
| --- | --- | --- | --- |
| uav / 1 | 3 consecutive eligible enemy kills | 15 s | Server-approved enemy minimap positions for activating player only |
| rage / 2 | 5 | 15 s | Eligible movement speed x1.20, reload duration x0.75; no damage or fire-rate buff |
| immortal / 3 | 8 | 8 s | Immune to ordinary combat damage, can shoot, no healing |

Central versioned registry; configurable for balancing, future scorestreak/extra bonus slots. No 20-second default. No helicopters/airstrikes/drone instead of requested features.

## State machine and timing
Per actor identity and match: progress >=0, earnedThisLife set, charges {uav,rage,immortal} each 0/1, active {id,startTick,endTick,activationId} or null, matchId/lifeId/controlEpoch and last accepted serial. Use shared simulation time/fixed ticks, not Date.now or client timers. Start match locked. At each confirmed eligible kill, increment once if source eligible and no bonus active/provenance exclusion. Cross each threshold once per life, mark earned even if existing carried charge occupies slot (no retroactive award); charge stays 1. On death progress=0, earned set reset, active ends, unused charges persist. Classic round transition ends active, unused charges persist same match; retain progress/earned for surviving life if life ID unchanged, otherwise reset on new life. New match/rematch resets all. Reconnect within seat reservation restores state, does not duplicate; expiration/seat replacement clears state. No bonus stacking. If active reject other activation without consuming charge. 
Activation request includes match/life/epoch/slot/monotonic serial; server resolves actual connected ready actor, validates active phase/alive/ownership/charge/not active/rate/serial, atomically consumes charge and sets effect with server tick. Idempotent duplicate rejects. No client-reported count, immunity, damage or speed. Offline runs same shared state machine; bots do not activate by default (document optional future balancing).
Expiry occurs at tick >= endTick. Effects start at activation tick, last exactly configured duration in simulation. Pause behavior follows authoritative match clock (offline pause freezes simulation; online menu does not pause). Define deterministic order: process validated activation at fixed-step boundary before new movement/shots, expire before evaluating damage at endTick; assert same ordering in tests.
## Eligibility
Eligible enemy combatant (human or opposing team bot) killed by credited source of same match/life/control epoch; FFA enemies use mode alliance predicate. Exclude self, team, neutral residents/hostages, invalid/stale damage, deaths credited to previous life for streak progress. Endless eligibility per mode; proposed allow hostile combatants, zombies excluded until mode-specific balance approved. Classic existing economy/score unaffected. Kill while any bonus active does not advance streak. Delayed projectile/grenade created while bonus active carries immutable bonus provenance, excluded even after expiry; also exclude if source has active bonus at impact/kill. Do not mutate historical event on reconnect. Kills still count for ordinary match score, subject to existing rules. At most one award per threshold per life, not per activation.
