Native Pi and emulated input measure different parts of the experience. Twelve full Floor 5 trials ran normal movement on the real Pi GPU with original/candidate door rendering. Emulated-touch frame p95 was 75.1/78.1/89.8 ms before and 49.3/48.6/42.2 ms after the change (cold, warm, warm). Keyboard p95 was 79.1/80.8/76.2 ms before and 43.7/46.5/42.3 ms after. These are historical controlled comparisons on the same Pi. The source-to-render and browser-delivery traces use browser event clocks. The two-seat first-HUD work also found a remaining 3.4–3.7 s input stall **during loading** and a later Floor 5 join-to-visible-HUD in the final comparison. Keep that investigation separate from steady-state gameplay. The release performance dossier owns the final soak and budget decision.
