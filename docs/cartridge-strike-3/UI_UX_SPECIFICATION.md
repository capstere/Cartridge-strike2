## Interaction and visual contract
Use original Tactical Industrial identity, restrained dark charcoal / muted warm accent, high contrast off-white type, no copied trademark, original cinematic lightweight art. Design tokens for colors, semantic teams, disabled/locked/focus/selected/error states, spacing and type; original/appropriately licensed fonts. Prefer semantic HTML and existing lightweight vanilla JS over a new framework. Game viewport consumes available space; no constant expensive background while match/preview active. Avoid unnecessary CSS motion, preserve reduced-motion setting. Use visual contrast plus labels/icons (not color alone). Desktop keyboard/Pointer Lock on match only; menu focus navigation, Back/Escape and browser history; touch targets at least 44 CSS px where feasible; iOS safe areas, scrolling/portrait menus, landscape match recommendation without blocking access. Show genuine progress, cancel, retry, actionable error and offline states. A menu preview is not a completed feature.

### Screen paths and acceptance
- Main → Play → Solo → choose mode/map/class/settings → Start → loading/countdown → game → results → Rematch/Main. Default recent valid configuration, guest without login.
- Main/Quick Join → authorized family invite → lobby; unauthorized → minimal proof step; reconnect restores seat if still reserved. With Friends create/join, link/QR, optional short join code; host alone controls settings; all see authoritative ready state. Public Matches is feature-flagged and disabled honestly until secure implementation and capacity/moderation gates.
- Classes → selected class / weapon details → attachment slots → preview → save → match. Classic loadout is preference only, not free purchases. Outfits → preview → select → validate online allowed appearance. Settings tabs Game, Audio, Video, Controls, Accessibility; persist automatically, per-device graphics and sensitivity, reset and confirm.
- Profile → guest/account → sign-in/register/recovery → profile/stats/cosmetics; sign-out and forget device. No email requirement if recovery codes are supported; no fake account server.
- News → real version manifest. HUD: timers, scoreboard, killfeed, minimap, objectives, ammo, hitmarkers, ready/locked/active bonus with textual countdown, thumb controls and pause.

## English release gate
English default and fallback across menu, match, network errors, HUD, tutorial, labels, tooltips, keyboard/gamepad hints, audio announcements/subtitles, map/mode labels, accessibility and patch notes. Use stable semantic keys with central locale catalog. Migrate legacy localStorage settings by ID; default English even on Swedish browser. Preserve player-supplied names verbatim. Retain Swedish historical docs, not Swedish UI literals. Add static string/key coverage check plus rendered screenshot and browser assertions across all screens, server notices and error branches. Automated scanning should distinguish user content, IDs, comments and labels. Future locale support via catalog (no duplicated markup).
