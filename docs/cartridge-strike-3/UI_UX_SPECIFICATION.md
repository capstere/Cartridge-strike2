## Screen journeys

- Main → Solo → map, settings and class → Start → loading → pre-deploy class confirmation → Deploy → countdown → match → results → Rematch or Main. Cancelling a panel restores the prior selection. In Classic, deploy and respawn follow round rules.
- Open a family alias or invite → proof when necessary → authoritative lobby → host settings and each player's Ready → play → reconnect/rematch. Include busy, full, denied and expired states. Public Matches opens only when the listing, account, moderation and capacity gates pass.
- Classes → inspect preset/locked slot → edit eligible slot/attachments → save → enter match. Outfits → rotate → select → verify matching in-match appearance. Options persist across restart and reflect available input and graphics capabilities.
- Give the Tactical Industrial interface high-contrast type, semantic focus, reduced motion, safe-area padding, scrollable menus and reachable actions at 44 CSS pixels where feasible. Use color and a second cue for team, selected, unavailable, damage and bonus states. Keep chat, pause, minimap, ammo, score and touch actions clear of the reticle and system cutouts. The left-edge pill also appears over menus and carries a recording indicator in the clips. Exclude it from the CS3 HUD.
- Capture all 16 states and equivalent in-match sequences at desktop 1280×720, 844×390 and 932×430 landscape, narrow portrait menus and high DPI. Record keyboard/Back, drag, pointer ownership, gamepad and physical iOS/Android results separately.

## English verification across the whole game

English is the required startup language and fallback. The current CS2 runtime contains Swedish. A catalog declaration alone cannot pass this gate.

| Surface and present evidence | Owner and proof required on the CS3 candidate |
| --- | --- |
| Static root redirect, noscript, credits, fps/index.html, loading/fatal states, install/offline/update prompts, server-rendered pilot invitation all have paths outside the main menu. The three HTML entry/credit documents and pilot form currently declare lang=sv. | Frontend and backend test both distributions, including before JavaScript and before authentication. Assert English document language, text, title, accessible names, live regions, error and retry. |
| app.mjs, ui/cs-mobile.mjs, combat/focus HUD, shop, scoreboard, network/menu, room-ui, session, match-flow and CSS-generated labels | Frontend inventories literals and all message keys. Unknown codes give a safe English fallback. In match-flow.mjs loading branches on “Bygger/Laddar”, and hud-shell.mjs classifies success by “köpt”. network/menu.mjs also decides whether to offer re-login by matching Swedish error text. Drive all three from typed state first. Demonstrate success and failure for each after translation. |
| config.mjs equipment/difficulty, action-rules/radio, game events, objectives, location/minimap labels, imported content errors, character-selection.mjs sv-SE dates | Gameplay and content owners map stable IDs to English, including signs painted by living-floor-art.mjs and route labels from tactical-map.mjs drawn by minimap-cache.mjs. Preserve player names and private save IDs verbatim. Review rendered map views and a legacy character/level import. Keep original attribution text where required. |
| Audio, subtitles, hints, profiles, generated news and server messages | Audio owner listens to each reachable spoken line and matches its English caption/key. Existing action radio recordings have English provenance in licenses/action-audio.txt. Validate selected packs, muted equivalents, plural/duration units and language after reconnect. Backend returns public error codes/parameters. |
| Riposte's 00-i18n.js selects French in some locales and returns source text on missing entries | Reuse formatting where suitable. Give CS3 its own English catalog and fallback. Test fresh en-US, sv-SE and fr-FR contexts, plus pre-existing settings, interrupted load and revoked sessions. |

Every package owns the English strings it introduces. The reviewer checks normal and failure paths in both the visible UI and accessibility tree, against expected English messages. Migrate Swedish text-based browser assertions to their English equivalents and keep the underlying behavioral assertions. Unexercised screens, untranslated world text or unreviewed spoken lines keep the release gate open.
