## Evidence to attach to a port

Use the existing implementation directly when units, state ownership and dependencies match. Adapt at the renderer, rig, level or input boundary when they differ. Keep Colyseus, rewind, family access, validated Classic purchases and custom/save compatibility. The official account backend and dedicated bonus authority need CS3 implementations.
